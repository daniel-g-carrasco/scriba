Scriba, Flatpak repository

This is where the Flatpak of Scriba lives. Current version: 0.1.1.

Install Scriba

Or from a terminal:

flatpak install https://daniel-g-carrasco.github.io/scriba/scriba.flatpakref

Updates arrive on their own, through GNOME Software or flatpak update. The GNOME runtime comes from Flathub.

Scriba is free software under GPL-3.0-or-later. Download the corresponding sources for this Linux package, including the collected dependency sources and build information, from the signed release files.

The repository is signed. The key's fingerprint is in the Linux documentation. Source and issues are on GitHub.
