Scriba

Record a meeting and transcribe it on your own computer, with speakers and subtitles.

Scriba records the microphone and computer sound on separate tracks, or opens an existing recording, and transcribes it locally. It writes text, subtitles and speaker names. Names can be corrected by reopening the meeting file, without transcribing again, and listening balance is saved as a new copy.

Early development

Windows is the current development target. There is no public installer or portable download yet. Linux Flatpak development builds are being verified; a public Flatpak repository is not available yet.

Automatic device selection uses system information and sound levels. Check the microphone, output and meters before recording. Live Bluetooth-headset call testing is still pending.

Source and development notes on GitHub

Audio and text are processed on your computer. Speech models are downloaded once and checked; Windows can also check for updates. Future release signing is described in the code signing policy.
